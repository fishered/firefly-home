# Firefly v1.1.2

发布日期：2026-09-01

v1.1.2 在 v1.1.1 调度语义与业务日历能力之上，完成生产代码的多模块工程拆分，并补齐批处理切分与依赖条件门控的基础实现。

## 本版本特性

- 根项目按 `libs`、`stores`、`transports`、`server`、`integrations`、`apis`、`clients` 和 `plugins` 聚合，核心能力拆分为独立 Gradle library；`scheduler-core` 保留旧版本兼容入口。
- 新增批处理分区 SPI 与范围分区实现，支持有界切分、批处理 checkpoint 校验和仓储幂等边界。
- 新增依赖条件门控模型，允许调度前按业务条件返回允许、等待或阻断，避免无限等待。
- JDBC 增量迁移与模块边界校验纳入构建；Docker、Starter、Netty、Admin 和 Maven 文档统一到 1.1.2。

## 数据库脚本

按数据库方言下载本版本的增量脚本：

- [PostgreSQL 脚本](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/postgresql)
- [MySQL 脚本](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/mysql)
- [H2 脚本](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/h2)

生产环境请先备份数据库，再按目标方言目录中的文件名顺序执行；也可以使用应用的增量 schema 初始化。

## 版本信息

- 旧版 `scheduler-core` 坐标继续可用；新项目可按模块引入，建议使用 `firefly-bom:1.1.2` 统一版本。
- Maven Central：`io.github.fishered:firefly-bom:1.1.2`
- 容器镜像默认标签：`1.1.2`

## 验证

发布前运行 `check`、`verifyModuleBoundaries`、`verifyReleaseVersion` 和 Admin UI 的 `npm run check`，并在 CI 中执行真实数据库与 Spring Boot 兼容性矩阵。
