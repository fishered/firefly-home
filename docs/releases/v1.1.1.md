# Firefly v1.1.1

发布日期：2026-08-30

v1.1.1 是一次以生产化基础和可操作性为重点的增量版本：调度语义、业务日历和批处理能力完成核心模型、持久化与运行时接线，Admin UI 也提供了可直接维护日历规则的交互界面。

## 本版本特性

- Admin 业务日历支持多月查看、多选、Ctrl/Command 追加、Shift 范围和拖拽框选，并可批量应用工作日、节假日或恢复默认类型。
- 新增日历、黑名单窗口、任务依赖、事件 Inbox、历史补数和批处理仓储等核心 SPI/模型；调度与结果链路保留 Outbox、root execution、retry 和 fencing 语义。
- JDBC 增量脚本增加日历元数据、日期规则和导入批次表；脚本是幂等和追加式的，不覆盖既有任务数据。
- Netty 执行结果异步接入批处理仓储，按 root execution、分片和 attempt 幂等保存，支持旧 attempt fencing、进度限频和 Prometheus 指标。
- 发布默认值、Docker 镜像示例、兼容矩阵和 Maven Central 发布流程统一到 1.1.1。

## 官方节假日 Provider 说明

本版本发布了 `HolidayProvider` SPI、数据集校验器和 classpath Provider 的生产接口，但不内置未经审核的官方年度数据，也未将任何静态示例数据宣称为法定节假日事实源。接入具体国家/地区时，应提供经过来源审计的年度数据包、SHA-256 校验和，并通过导入批次执行预览、校验和发布。
