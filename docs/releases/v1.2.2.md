# Firefly v1.2.2

发布日期：2026-11-23

本版本围绕“接入 → 创建 → 运行 → 诊断 → 调整”组织 Admin 工作路径，减少用户自行拼接功能入口的步骤。

## 本次交付

- 首次接入页检查 API 与数据库、Gateway、认证、Integration Key、在线 Executor、已注册 Handler 和首个成功任务，并生成使用环境变量注入密钥的 Spring Boot 配置。
- 任务创建改为执行目标、调度规则、资源策略、预览确认四步；高级策略默认折叠。
- 待处理中心集中展示当前加载数据中的失败执行、离线 Executor、派发死信、失败事件、异常补数、租户容量风险和节点异常，并提供关联入口。
- 执行详情读取现有 timeline API，按触发、配额准入、Outbox、Gateway、ACK、执行、重试/重放展示诊断与建议。
- 导航归并为五组；增加全局搜索、可恢复的 URL 筛选、状态与资源单位说明。任务和租户修改先预览；任务编辑通过 `expectedVersion` 原子校验，冲突时保留输入并要求重新预览。

## 兼容性与边界

本版本未增加调度协议或数据库迁移。现有 `firefly_job.version` 也随调度游标推进，活跃任务的预览可能因此过期。待处理中心使用当前分页数据，不代表完整告警历史。配额准入与 Outbox 尚无精确持久化事件，时间线明确标记“暂无观测数据”。
