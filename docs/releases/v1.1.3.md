# Firefly v1.1.3

发布日期：2026-09-03

v1.1.3 围绕“业务时间窗口、数据就绪和可恢复执行”扩展 Firefly，继续复用 execution、Dispatch Outbox、CAS 和 fencing 边界，不引入完整 DAG 引擎。

## 本次交付

- 新增 `DataReadyCondition` / `DataReadyConditionEvaluator` 数据就绪条件 SPI，支持多个条件组合、`WAITING`、`BLOCKED` 和未知条件 fail-closed；Server 支持通过 classpath `ServiceLoader` 装配条件。
- 新增事件聚合与防抖模型，支持 aggregation key、debounce、max delay、latest payload、event count 和幂等事件 inbox，避免事件洪峰直接放大为大量 execution。
- 新增可恢复补数协调器，支持有界预览、批次运行、暂停/继续/取消、金丝雀放量、失败时间筛选、限速和断点进度。
- 新增执行重放计划，支持 dry-run、任务/日历/依赖/参数差异检查、失败目标筛选和 root execution 关联。
- 新增资源感知执行器选择与 SLA 预算模型，支持 CPU、内存、标签、租户并发预算以及排队/启动/完成阶段评估。
- 新增业务结果摘要和调度输入 revision，统一输入/成功/失败计数、checkpoint、结果位置、SHA-256 摘要和版本差异说明。

## 接入边界

本版本已发布公共模型、SPI、核心服务和内存协调器；数据就绪条件已接入 Server runtime。事件聚合状态、补数游标、重放接口和资源快照尚未接入 JDBC 持久化或 Admin HTTP/UI，后续接线必须继续通过现有 execution/Outbox、CAS 和 fencing 机制完成。
