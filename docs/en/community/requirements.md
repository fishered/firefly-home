# Submit Requests

Use GitHub Issues for feature requests, bugs, and documentation improvements:

[Open Firefly Issues](https://github.com/fishered/Firefly/issues)

## Useful Information

- Usage mode: embedded, Spring Boot, standalone Server, or remote Executor
- Expected behavior: how Firefly should schedule, dispatch, retry, or display state
- Current behavior: logs, configuration, and reproduction steps for bugs
- Runtime environment: JDK, database, deployment mode, and node roles
- Risk boundary: time zones, DST, cluster failover, idempotency, or timeouts

For behavior changes, please describe whether existing job semantics are affected.
