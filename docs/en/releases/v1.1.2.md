# Firefly v1.1.2

Release date: September 1, 2026

v1.1.2 builds on the scheduling and business-calendar capabilities of v1.1.1 with a production-oriented multi-module project layout and foundations for bounded batch partitioning and dependency condition gates.

## Features in this version

- The root project is organized into `libs`, `stores`, `transports`, `server`, `integrations`, `apis`, `clients`, and `plugins` aggregators; core capabilities are independent Gradle libraries while `scheduler-core` remains as a compatibility entry point.
- Added batch partitioning SPI and range partitioner with bounded splits, checkpoint validation, and idempotent repository boundaries.
- Added dependency condition-gate models that return allow, wait, or block before dispatch, avoiding unbounded waiting.
- JDBC additive migrations and module-boundary verification are part of the build; Docker, Starter, Netty, Admin, and Maven documentation are aligned to 1.1.2.

## Database scripts

Download the incremental scripts for your database dialect:

- [PostgreSQL scripts](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/postgresql)
- [MySQL scripts](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/mysql)
- [H2 scripts](https://github.com/fishered/Firefly/tree/v1.1.2/stores/jdbc/src/main/resources/com/firefly/store/jdbc/schema/migrations/h2)

Back up the production database first, then apply the files in filename order for the selected dialect. Additive schema initialization remains supported.

## Version information

- The legacy `scheduler-core` coordinates remain available; new projects can use individual modules and should align versions with `firefly-bom:1.1.2`.
- Maven Central: `io.github.fishered:firefly-bom:1.1.2`
- Container default tag: `1.1.2`

## Verification

Run `check`, `verifyModuleBoundaries`, `verifyReleaseVersion`, and the Admin UI `npm run check` before publishing. CI also runs the real-database and Spring Boot compatibility matrix.
